# StoryWeave 배포 저장소

한국어 웹소설 작가를 위한 로컬 집필 프로그램 **StoryWeave**의 Windows 배포 파일과 업데이트 정보를 두는 공개 저장소입니다.
프로그램 소스 코드는 이곳에 없습니다.

- 내려받기: 이 저장소의 [Releases](https://github.com/godgyu77/StoryWeave-Releases/releases) — 첫 공개 배포는 베타(Pre-release)입니다.
- 처음 설치하는 방법: [INSTALL.md](INSTALL.md)
- 버전별 변경 내용: [CHANGELOG.md](CHANGELOG.md)

## 업데이트는 어떻게 받나요

업데이트 기능이 들어간 버전부터는 프로그램 안에서 받을 수 있습니다.

1. StoryWeave에서 작품을 연 뒤 **설정 → 프로그램 정보**로 갑니다.
2. **업데이트 확인**을 누르면 새 버전과 변경 내용이 보입니다.
3. **업데이트 받기**를 누르면 파일을 받고, 받은 파일이 배포자가 서명한 파일인지 확인합니다. 아직 설치하지 않습니다.
4. 설치하기 전에 **모든 탭에서 저장합니다**: 원고, 회차 메모·작가의 말, 등장인물·설정집·관계 입력, 작품 설정. AI 도움 입력칸에 쓰다 만 요청은 보내거나 복사해 둡니다. StoryWeave 탭은 하나만 남기고, 다른 브라우저에 열어 둔 StoryWeave 창도 닫습니다.
5. **"모든 탭과 다른 브라우저에서 쓰던 것을 저장했고, 이 탭 말고 다른 StoryWeave 창은 닫았습니다"**에 체크합니다. 체크해야 **설치하고 다시 시작**이 눌립니다. StoryWeave는 다른 브라우저의 글이나 입력 칸에 남은 글까지 스스로 확인하지 못합니다.
6. **설치하고 다시 시작** → **설치**를 누르면 StoryWeave가 잠시 닫혔다가 새 버전으로 다시 열립니다. **설치 직전에 열려 있던 작품은 새 버전에서 자동으로 다시 열립니다.**
7. "새 버전으로 다시 시작했습니다"가 뜨면, 저장하지 않은 입력이 남은 탭은 **먼저 그 자리에서 저장한 뒤** 새로 고칩니다.

- 설치는 항상 직접 누를 때만 합니다. 새 버전 확인만 프로그램을 열 때 자동으로 하도록 켤 수 있습니다(기본은 꺼짐).
- 이 브라우저의 다른 탭에 저장하지 않은 원고가 있거나, AI 작업 중이거나, ChatGPT 로그인 중이면 체크해도 설치 단추가 잠깁니다.
- **새로 고치기 전에 반드시 저장하세요.** 원고 초안 보관이 없는 입력(회차 메모·작가의 말, 등장인물·설정집·관계·작품 설정 입력, AI 도움 입력칸, 초안 보관을 끈 원고)은 새로 고치면 사라집니다. 이런 입력이 남은 탭을 새로 고치거나 닫으려 하면 브라우저가 경고하니, [취소]를 누르고 먼저 저장하세요.
- 인터넷이 없거나 확인에 실패해도 집필은 그대로 할 수 있습니다.
- 새 버전이 제대로 시작되지 않으면 원래 버전으로 자동으로 되돌리고 창으로 알려 줍니다. 이때는 쓰던 작품이 자동으로 열려 있지 않을 수 있습니다("문제가 생겼을 때").
- 작품, 설정, 회차 버전 기록, AI 연결 정보는 업데이트가 건드리지 않습니다.

> **베타 0.1.7·0.1.8을 쓰는 경우:** 이 버전들에는 업데이트 기능이 없습니다. 업데이트 기능이 들어간 첫 베타(v0.1.9-beta.1)는 한 번만 ZIP으로 직접 받아 예전 실행 파일 대신 `StoryWeave-Beta.exe`를 실행하면 되고, 쓰던 작품과 ChatGPT 로그인은 같은 폴더에 있어 그대로 이어집니다([INSTALL.md](INSTALL.md)). 그 다음부터는 프로그램 안에서 받을 수 있습니다.

## 버전과 채널

- 정식판: `v0.2.0`처럼 붙습니다.
- 베타: `v0.2.1-beta.1`처럼 붙고, GitHub에서 "Pre-release"로 표시됩니다.
- 정식판을 쓰면 정식판 업데이트만 받습니다. 베타를 쓰면 더 새로운 베타나 정식판을 받습니다.
- 같은 버전을 다시 설치하거나 더 낮은 버전으로 내려가는 업데이트는 하지 않습니다.
- 작품 저장 형식을 바꾸는 버전은 자동 업데이트로 설치하지 않습니다. 그런 버전은 따로 안내합니다.

## 각 릴리스에 들어 있는 파일

| 파일 | 용도 |
|---|---|
| `StoryWeave-Beta-<버전>-win-x64.zip` | **처음 설치할 때 받는 파일.** `StoryWeave-Beta.exe`와 사용 안내, 배포 정보(`RELEASE_NOTES.md`, `RELEASE_INFO.txt`) |
| `StoryWeave-Beta-<버전>-SHA256SUMS.txt` | 위 ZIP과 그 안의 `StoryWeave-Beta.exe`의 SHA-256 |
| `StoryWeave-<버전>-windows-amd64.exe` | 프로그램 안 업데이트가 받는 파일. 직접 받아 실행하지 마세요(파일 이름에 버전이 붙어 업데이트 뒤에도 남습니다) |
| `storyweave-update.json` | 버전, 채널, 파일 이름·크기·SHA-256, 변경 내용 |
| `storyweave-update.json.sig` | 위 정보에 대한 배포자의 전자서명 (Ed25519) |

프로그램 안 업데이트는 위 표의 세 파일(`…-windows-amd64.exe`, `storyweave-update.json`, `.sig`)만 씁니다.

프로그램은 GitHub의 정보만 믿지 않습니다. 프로그램 안에 든 공개키로 `storyweave-update.json`의 서명을 먼저 확인하고,
받은 프로그램 파일의 크기와 SHA-256이 서명된 값과 같을 때만 설치합니다.

- 지문(위 공개키 한 줄의 SHA-256): `c1914d23783a6ceb4cbffe1fdf05aa3eacf9ce2bcb166d39a193ed0e1e37b35b`

이 서명은 Windows 코드 서명(인증서)과 다릅니다. StoryWeave 실행 파일에는 Windows 코드 서명이 없어서, 처음 실행할 때 "Windows의 PC 보호"(알 수 없는 게시자) 창이 뜰 수 있습니다. 업데이트 서명은 프로그램 안에서 받은 업데이트 파일이 개발자가 만든 그대로인지 StoryWeave가 확인하는 데 씁니다.

## 문제가 생겼을 때

- **"…제대로 시작되지 않아 …(으)로 되돌렸습니다"** 창이 뜨면 이전 버전이 다시 실행 중이고, 작품·설정·ChatGPT 연결은 그대로입니다. 다만 쓰던 작품이 **자동으로 열려 있지 않을 수 있습니다**(저장을 누르면 "먼저 작품을 선택하세요"). 이때 저장하지 않은 입력이 남은 탭은 새로 고치거나 닫지 말고:
  1. **새 탭**에서 `http://127.0.0.1:48190`을 열고, 작품 목록에서 **같은 작품**을 엽니다.
  2. 원래 탭으로 돌아가 그 자리에서 저장합니다.

  다른 작품을 열면 원래 탭의 저장은 거부되고 글은 화면에 남습니다. 이 동작은 다음 베타에서 고칠 예정입니다.
- 업데이트도 되돌리기도 마치지 못했다는 안내가 나오면, `StoryWeave-Beta.exe`가 있는 폴더의 숨김 폴더 `.storyweave-update\backup` 안에 바뀌기 전 프로그램 파일(`StoryWeave-Beta-v<바뀌기 전 버전>.exe`) 하나가 있습니다. [INSTALL.md](INSTALL.md)의 "직접 되돌리기"를 따라 주세요.
- 버그나 질문은 이 저장소의 Issues에 남겨 주세요. 원고 내용, API 키, 로그인 정보는 올리지 마세요.
