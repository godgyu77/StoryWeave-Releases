# StoryWeave 배포 저장소

한국어 웹소설 작가를 위한 로컬 집필 프로그램 **StoryWeave**의 Windows 배포 파일과 업데이트 정보를 두는 공개 저장소입니다.
프로그램 소스 코드는 이곳에 없습니다.

- 내려받기: 이 저장소의 [Releases](https://github.com/godgyu77/StoryWeave-Releases/releases)
- 처음 설치하는 방법: [INSTALL.md](INSTALL.md)
- 버전별 변경 내용: [CHANGELOG.md](CHANGELOG.md)

## 업데이트는 어떻게 받나요

업데이트 기능이 들어간 버전부터는 프로그램 안에서 받을 수 있습니다.

1. StoryWeave에서 작품을 연 뒤 **설정 → 프로그램 정보**로 갑니다.
2. **업데이트 확인**을 누르면 새 버전과 변경 내용이 보입니다.
3. **업데이트 받기**를 누르면 파일을 받고, 받은 파일이 배포자가 서명한 파일인지 확인합니다.
4. **설치하고 다시 시작**을 누르면 StoryWeave가 잠시 닫혔다가 새 버전으로 다시 열립니다.

- 설치는 항상 직접 누를 때만 합니다. 새 버전 확인만 프로그램을 열 때 자동으로 하도록 켤 수 있습니다(기본은 꺼짐).
- 인터넷이 없거나 확인에 실패해도 집필은 그대로 할 수 있습니다.
- 새 버전이 제대로 시작되지 않으면 원래 버전으로 자동으로 되돌립니다.
- 작품, 설정, 회차 버전 기록, AI 연결 정보는 업데이트가 건드리지 않습니다.

> **베타 0.1.7·0.1.8을 쓰는 경우:** 이 버전들에는 업데이트 기능이 없습니다. 업데이트 기능이 들어간 첫 버전은 한 번만 직접 받아 설치해야 하고, 그 다음부터 프로그램 안에서 받을 수 있습니다.

## 버전과 채널

- 정식판: `v0.2.0`처럼 붙습니다.
- 베타: `v0.2.1-beta.1`처럼 붙고, GitHub에서 "Pre-release"로 표시됩니다.
- 정식판을 쓰면 정식판 업데이트만 받습니다. 베타를 쓰면 더 새로운 베타나 정식판을 받습니다.
- 같은 버전을 다시 설치하거나 더 낮은 버전으로 내려가는 업데이트는 하지 않습니다.
- 작품 저장 형식을 바꾸는 버전은 자동 업데이트로 설치하지 않습니다. 그런 버전은 따로 안내합니다.

## 각 릴리스에 들어 있는 파일

| 파일 | 용도 |
|---|---|
| `StoryWeave-<버전>-windows-amd64.exe` | 프로그램 파일 (업데이트가 받는 파일) |
| `storyweave-update.json` | 버전, 채널, 파일 이름·크기·SHA-256, 변경 내용 |
| `storyweave-update.json.sig` | 위 정보에 대한 배포자의 전자서명 (Ed25519) |
| `StoryWeave-<버전>-windows-amd64.zip` | 처음 설치용 묶음 (있는 경우) |

프로그램은 GitHub의 정보만 믿지 않습니다. 프로그램 안에 든 공개키로 `storyweave-update.json`의 서명을 먼저 확인하고,
받은 프로그램 파일의 크기와 SHA-256이 서명된 값과 같을 때만 설치합니다.

## 서명 공개키

배포 서명 키가 정해지면 여기에 키 이름과 공개키, 지문을 적습니다. (아직 공개 릴리스가 없습니다.)

## 문제가 생겼을 때

- 업데이트가 끝나지 않았거나 되돌리지 못했다는 안내가 나오면 프로그램 폴더의 `.storyweave-update\backup` 안에 이전 프로그램 파일이 있습니다. [INSTALL.md](INSTALL.md)의 "직접 되돌리기"를 따라 주세요.
- 버그나 질문은 이 저장소의 Issues에 남겨 주세요. 원고 내용, API 키, 로그인 정보는 올리지 마세요.
